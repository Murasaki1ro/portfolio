## ✨ Customization Examples

### Change Colors
```css
/* Old */
--primary-color: #6366f1;

/* New - Green Theme */
--primary-color: #10b981;
--secondary-color: #06b6d4;
```

### Change Font
```css
/* Old */
font-family: 'Segoe UI', sans-serif;

/* New */
@import url('https://fonts.googleapis.com/css2?family=Poppins');
font-family: 'Poppins', sans-serif;
```

### Add New Section
Copy existing section in HTML, modify:
- Section ID
- Content
- Classes
- Animation classes

### Customize Animations
```css
/* Change duration */
.slide-in-up {
    animation: slideInUp 0.3s ease-out;  /* Was 0.6s */
}

/* Change easing */
animation: slideInUp 0.6s ease-in-out;  /* Was ease-out */
```
